MAIN:
    Parse command-line arguments:
        --file: Input file containing initial board state
        --amount: Number of iterations
        --silent: If true, do not print

    Initialize the board:
        Load the initial state from file into a 2D array

    RUN GAME OF LIFE:
        If started with --server:
        Print READY to stdout and flush
        Loop reading lines from stdin:
            If line == "SHUTDOWN": exit loop and terminate
            If line starts with "RUN ":
                Parse request: RUN <file> <amount>
                Load the board from <file>
                Run the game loop for <amount> iterations 
                If not in --silent mode: print final board to output.txt
                Write response: DONE and flush
            Else: write an ERROR response

    If not in --silent mode:
        Print the final board state to the output.txt

    Exit successfully

FUNCTIONS:
    Compute Next State(board):
        Create a new empty 2D array for the next state
        For each cell (x, y) in the board:
            Count live neighbors of (x, y)
            Apply Game of Life rules:
                If the cell is alive:
                    Survives if neighbors == 2 or 3; otherwise dies
                If the cell is dead:
                    Comes to life if neighbors == 3
        Return the new board state

    Count Live Neighbors(board, x, y):
        Initialize count = 0
        Loop through 3x3 neighborhood centered on (x, y) wrapping around the edges: 
            Skip the center cell itself
            If the neighbor cell is alive, increment count
        Return count
